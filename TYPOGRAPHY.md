# Типографика Boat Reserve V4.9

Основной стек не загружает шрифты из сети и одинаково стабильно работает на Windows, Android и macOS:

```css
font-family: "Segoe UI Variable Text", "Segoe UI", system-ui, -apple-system, BlinkMacSystemFont, Arial, sans-serif;
```

На Windows 10 используется системный Segoe UI. В проект не включены внешние файлы шрифтов.

Что исправлено в V4.9:

- удалены нестандартные веса 750/780/800/850, которые разные браузеры синтезировали по-разному;
- оставлены стандартные веса 400/600/700;
- увеличен межстрочный интервал у заголовков, цен, плашек и текста карточек;
- уменьшен отрицательный межбуквенный интервал для кириллицы;
- глобальный стиль `h2` больше не вмешивается в модальные окна и служебные блоки;
- включены нормальный кернинг и сглаживание текста;
- элементы форм и кнопки получили собственный безопасный `line-height`.
