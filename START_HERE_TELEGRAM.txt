SPB_BOAT + TELEGRAM BOT — БЫСТРЫЙ СТАРТ

Подключён новый бот:
Имя: SPB_boat
Username: @SPB_boat_bot

1. Запустите run_windows.cmd.
2. Дождитесь строки о запуске сервера и Telegram-бота.
3. Откройте @SPB_boat_bot и отправьте /start.
4. При первом запуске проект сам заполнит имя, описания, команды и меню бота.
5. Для отдельной настройки профиля запустите setup_telegram.cmd.
6. Для проверки токена и имени запустите check_telegram.cmd.
7. Статус интеграции в браузере:
   http://127.0.0.1:8000/v1/telegram/status
8. Чтобы назначить себя администратором:
   - отправьте боту /id;
   - скопируйте число;
   - замените ADMIN_TELEGRAM_IDS=10001 в .env;
   - перезапустите run_windows.cmd.

Локальная кнопка открывает http://127.0.0.1:8000.
Для полноценной Mini App внутри Telegram нужен публичный HTTPS-адрес,
который затем указывается в MINI_APP_URL файла .env.

Подробная инструкция: TELEGRAM_BOT_SETUP.md

ВАЖНО: токен находится только в .env. После тестирования замените его через BotFather.


ВАЖНО: бот не работает сам по себе после создания в BotFather. Пока run_windows.cmd или START_BOT_ONLY.cmd не запущен и окно закрыто, команды /start и /id останутся без ответа. Для первого получения ID проще использовать START_BOT_ONLY.cmd.
