# Сценарий предоплаты — Boat Reserve V5.1

## Клиент

1. Выбирает катер, дату, время, длительность и количество гостей.
2. Приложение создаёт предбронь и удерживает время.
3. Открывается экран **«Предоплата по СБП»**:
   - точная сумма;
   - номер `+7 978 800-20-72`;
   - кнопка копирования;
   - пояснение, что перевод можно сделать через любой удобный банк.
4. После перевода клиент нажимает **«Я оплатил»**.
5. Заявка переходит в статус **«Проверка оплаты»**. Приложение автоматически проверяет обновление статуса.

## Администратор

1. Заявка появляется в очереди оплат диспетчерской.
2. Администратор проверяет поступление в банке.
3. Нажимает **«Подтвердить оплату»** либо **«Платёж не найден»**.
4. При подтверждении сервер повторно проверяет доступность катера и создаёт окончательную бронь.

## После подтверждения

Клиент автоматически получает:

- название катера;
- дату и время;
- продолжительность;
- количество гостей;
- причал и адрес отправления;
- сумму предоплаты и остаток;
- приветственное сообщение и рекомендации из листа **«Шаблоны»**;
- ссылку на событие Google Календаря, когда интеграция подключена.

Одновременно бронь сохраняется:

- в основной базе Boat Reserve;
- в листе **«Подтвержденные брони»**, когда включена Google-запись;
- в Google Календаре, когда подключён календарь;
- в журнале действий администратора.

## Управление через Google Sheets

Лист **«Настройки»**:

- `payment_phone` — номер для СБП;
- `payment_method` — способ оплаты;
- `payment_bank_note` — подсказка клиенту;
- `payment_recipient_name` — имя получателя, при необходимости;
- `google_write_enabled` — запись подтверждённых броней;
- `google_calendar_enabled` — создание событий;
- `google_calendar_id` — ID рабочего календаря.

Лист **«Шаблоны»**:

- `payment_instructions_private` — экран оплаты;
- `booking_confirmed_private` — подтверждение брони;
- `welcome_recommendations` — рекомендации клиенту;
- `payment_rejected` — сообщение, если платёж не найден.

Доступные переменные шаблона:

```text
{boat_name}
{date}
{time}
{duration}
{guests_total}
{berth_name}
{berth_address}
{prepayment_amount}
{remainder_amount}
{payment_phone}
{recommendations}
```
