# Boat Reserve v6.2 — устойчивый публичный запуск

- Основной запуск перенесён из большого PowerShell-сценария в стандартный Python launcher.
- Исправлено чтение пустых логов Pinggy: `None` больше не передаётся в regex.
- Используется официальная SSH-команда Pinggy через TCP 443.
- Cloudflare остаётся резервом и скачивается тихо только один раз.
- Зависимости не переустанавливаются при каждом запуске: используется SHA-256 отметка requirements.txt.
- Локальный сайт остаётся доступным даже при неудаче публичного туннеля.
- Добавлено автоматическое восстановление публичного маршрута при обрыве.
- Переписаны STOP и DIAGNOSE без хрупкой логики PowerShell.
- CMD-файлы: ASCII без BOM, CRLF.
