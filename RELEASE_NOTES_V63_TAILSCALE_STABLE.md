# Boat Reserve v6.3 — стабильный публичный адрес

## Причина предыдущей ошибки

Локальный FastAPI-сервер работал, но адрес `trycloudflare.com` был недоступен из браузера
через текущий маршрут VPN/провайдера. Это не ошибка FastAPI и не ошибка базы.

## Новая схема

Основной публичный вход переведён на Tailscale Funnel:

- постоянный HTTPS-адрес в домене `ts.net`;
- приложение и база остаются на ноутбуке;
- адрес не меняется после перезапуска;
- внешний пользователь не устанавливает Tailscale;
- Cloudflare больше не скачивается автоматически при каждом запуске.

## Первый запуск

Один раз запустить `SETUP_STABLE_PUBLIC_ACCESS.cmd`, войти в Tailscale и разрешить Funnel.
После этого обычный запуск выполняется через `START_PUBLIC_SITE_AND_BOT.cmd`.

## Порт

Для постоянной привязки используется локальный порт `8787`. Старые процессы проекта
завершаются автоматически. Если этот порт занят посторонней программой, запуск сообщит об этом.
