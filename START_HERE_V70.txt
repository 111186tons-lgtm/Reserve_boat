BOAT RESERVE V7.0 — МОБИЛЬНЫЙ MINI APP + GOOGLE

ЧТО ВКЛЮЧЕНО
- Клиентское приложение внутри Telegram и в обычном мобильном браузере.
- Мобильная диспетчерская для администратора 706944976.
- Вход в обычном браузере по коду 44444444.
- Подтверждение/отклонение оплаты прямо кнопками в Telegram.
- Уведомления клиенту после подтверждения оплаты.
- Google Sheets как главный каталог и источник настроек.
- Запись подтверждённых броней в лист «Подтвержденные брони».

- 2 причала: канал Грибоедова, 131 и канал Грибоедова, 59.

ОБЫЧНЫЙ ЗАПУСК
1. Запустите START_PUBLIC_SITE_AND_BOT.cmd.
2. Не закрывайте окно, пока сайт и бот должны работать.
3. В Telegram откройте @SPB_boat_bot и отправьте /start.
4. Для диспетчерской отправьте /admin или откройте кнопку меню.

ПОДКЛЮЧЕНИЕ GOOGLE ДЛЯ ЗАПИСИ И КАЛЕНДАРЕЙ
Чтение опубликованной таблицы работает без ключа. Для записи броней и календарей:
1. В Google Cloud включите Google Sheets API и Google Calendar API.
2. Создайте OAuth Client типа Desktop app.
3. Сохраните JSON рядом с этим файлом под именем google-oauth-client.json.
4. Запустите CONNECT_GOOGLE.cmd и разрешите доступ в браузере.
5. Скрипт создаст/найдёт отдельный календарь для каждого опубликованного катера и внесёт его ID в лист «Катера».
6. Перезапустите Boat Reserve и нажмите «Google Sheets» в диспетчерской.

ОБНОВЛЕНИЕ СТАРОЙ РАБОЧЕЙ ПАПКИ
Скопируйте файлы патча поверх старой папки, не заменяя .env и boat_reserve.db, затем запустите APPLY_V70_UPDATE.cmd.

ВАЖНО
- Google-таблица «Бронь Катеров» уже заполнена катерами, причалами, настройками и шаблонами.
- Реальные существующие брони не удаляются при обновлении через APPLY_V70_UPDATE.cmd.
- Файлы .env, google-oauth-token.json и токен бота нельзя публиковать.
