# Boat Reserve 5.4 — Public Local

## Публичная работа с ноутбука

Добавлен `START_PUBLIC_SITE_AND_BOT.cmd`. Он создаёт бесплатный Cloudflare Quick Tunnel к локальному FastAPI на `127.0.0.1:8000`, получает HTTPS-адрес и запускает Telegram polling с этим адресом.

## Безопасность публичного режима

- `DEV_AUTH_ENABLED=false` — общий тестовый пользователь `10001` отключён.
- Посетители обычного сайта получают отдельную локальную гостевую сессию.
- Гостевой идентификатор рассчитывается HMAC и не раскрывает исходный session ID.
- Telegram Mini App продолжает проверять подписанный `initData`.
- Администратор Telegram определяется по `ADMIN_TELEGRAM_IDS=706944976`.
- Telegram-администратор открывает диспетчерскую без кода.
- Для аварийного браузерного входа создан отдельный случайный код.
- Swagger/OpenAPI отключаются в режиме `public-local`.
- Перед запуском создаётся резервная копия SQLite.

## Telegram-диспетчер

Администратор получает:

1. сообщение о новой заявке;
2. сообщение о нажатии клиентом «Я оплатил»;
3. inline-кнопки подтверждения или отклонения оплаты;
4. кнопку открытия диспетчерской.

Подтверждение из Telegram использует ту же бизнес-логику, что и веб-диспетчерская: создаёт бронь, освобождает/конвертирует hold, записывает аудит и отправляет подтверждение клиенту.

## Связка обычного сайта с Telegram

Посетители сайта больше не объединяются в одного тестового клиента. Для заявки создаётся подписанная deep-link ссылка `t.me/...?...`, через которую клиент может привязать конкретный заказ к своему Telegram-аккаунту. После привязки подтверждения и отказы приходят в бот.
