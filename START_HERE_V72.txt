BOAT RESERVE V7.2 — FULL WORKING BUILD

Эта сборка сделана непосредственно из присланной рабочей V7.1.
Все исходные файлы V7.1 сохранены: интерфейс, фотографии, база, тесты, Telegram, Google и публичный launcher.

КАК ЗАПУСТИТЬ
1. Полностью распакуйте ZIP. Не запускайте файлы прямо из архива.
2. Откройте распакованную папку.
3. Запустите START_ALL.cmd.

START_ALL.cmd вызывает тот же проверенный launcher, который использовался в V7.1:
START_PUBLIC_SITE_AND_BOT.cmd

Остановка: STOP_ALL.cmd или STOP_BOAT_RESERVE.cmd.

Настройки V7.2:
- Telegram: @SPB_boat_bot;
- новый токен уже находится в .env;
- перенастройка профиля Telegram при каждом старте отключена;
- Google Sheets работает по активности;
- периодический опрос каждые 5 минут отключён;
- API /health показывает версию 7.2.0.

ОБНОВЛЕНИЕ V7.2.1 ДЛЯ ТЕЛЕФОНА
После запуска обязательно отправьте боту /start и используйте кнопку из НОВОГО сообщения.
Старые сообщения Telegram могут хранить уже истёкший временный HTTPS-адрес.
Если основной вход не открылся, используйте кнопку «Резервный вход».
Для постоянной ссылки один раз запустите SETUP_STABLE_PUBLIC_ACCESS.cmd.
