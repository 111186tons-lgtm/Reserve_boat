# V5.5 — исправление публичного запуска

Исправлена гонка запуска: раньше браузер открывал адрес Quick Tunnel до того, как FastAPI завершал запуск. Теперь порядок строгий:

1. создаётся HTTPS-туннель;
2. запускается FastAPI и Telegram polling;
3. проверяется `http://127.0.0.1:8000/health`;
4. проверяется публичный `/health`;
5. только после двух успешных проверок открывается браузер.

Дополнительно:

- `cloudflared` использует автоматический выбор протокола вместо принудительного HTTP/2;
- процессы сайта и туннеля контролируются отдельно;
- ошибки приложения и Cloudflare выводятся в окно запуска;
- добавлен `DIAGNOSE_PUBLIC_SITE.cmd`;
- актуальный адрес всегда сохраняется в `PUBLIC_URL.txt`;
- старые ссылки `trycloudflare.com` после перезапуска считаются недействительными.
