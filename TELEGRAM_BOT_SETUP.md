# Telegram-бот SPB_boat: подключение и тестирование

## Подключённый бот

- **Имя:** `SPB_boat`
- **Username:** `@SPB_boat_bot`
- Токен записан в локальный файл `.env`.
- В конфигурации задана проверка `TELEGRAM_BOT_EXPECTED_USERNAME=SPB_boat_bot`. Если в `.env` случайно окажется токен другого бота, проект остановит Telegram-интеграцию и покажет понятную ошибку.

## Что проект делает автоматически

Бот запускается вместе с FastAPI-приложением через `run_windows.cmd`. При старте проект:

- проверяет токен через Telegram Bot API;
- проверяет, что токен принадлежит именно `@SPB_boat_bot`;
- отключает старый webhook, чтобы локальный polling не конфликтовал с ним;
- регистрирует команды `/start`, `/app`, `/id`, `/help`, `/admin`;
- устанавливает имя `SPB_boat`;
- заполняет полное и короткое описание;
- в локальном режиме включает стандартное меню команд Telegram;
- принимает сообщения через long polling;
- создаёт или обновляет пользователя в таблице `users`;
- сохраняет присланный номер телефона;
- показывает клиенту кнопку каталога;
- показывает администратору кнопку диспетчерской;
- отправляет клиентам уведомления о подтверждённых бронях.

## Первый запуск

1. Запустите `run_windows.cmd`.
2. Откройте в Telegram `@SPB_boat_bot`.
3. Отправьте `/start`.
4. Откройте сайт: `http://127.0.0.1:8000/`.
5. Проверьте статус: `http://127.0.0.1:8000/v1/telegram/status`.

Профиль бота можно настроить отдельно командой `setup_telegram.cmd`. Проверить токен, имя и webhook можно командой `check_telegram.cmd`.

## Назначение администратора

Отправьте боту `/id`, скопируйте полученное число и внесите его в `.env`:

```env
ADMIN_TELEGRAM_IDS=ВАШ_TELEGRAM_ID
```

После изменения перезапустите `run_windows.cmd`. Тогда команда `/admin` и кнопка диспетчерской станут доступны вашему аккаунту.

## Полноценная Mini App внутри Telegram

Telegram разрешает кнопку типа Web App только для публичного адреса `https://`. Сейчас используется локальный адрес:

```env
MINI_APP_URL=http://127.0.0.1:8000
```

После публикации приложения укажите публичный HTTPS-адрес:

```env
MINI_APP_URL=https://example.com
```

При следующем запуске проект автоматически заменит меню команд на постоянную кнопку **«Забронировать»** и Mini App начнёт получать подписанный `initData` от Telegram.

После публикации отключите демонстрационную авторизацию:

```env
DEV_AUTH_ENABLED=false
```

## Polling и webhook

Для локального запуска используется:

```env
TELEGRAM_POLLING_ENABLED=true
```

Для webhook нужен публичный HTTPS-адрес `/webhooks/telegram`, секрет из `TELEGRAM_WEBHOOK_SECRET` и отключённый polling:

```env
TELEGRAM_POLLING_ENABLED=false
```

## Безопасность

`.env` исключён из Git через `.gitignore`. Токен не записан в Python-код, документацию или `.env.example`. После тестирования отзовите текущий токен в BotFather и замените `TELEGRAM_BOT_TOKEN` в `.env`.
