# Boat Reserve v7.2.2 — исправление публичного доступа на телефоне

Исправлена ситуация, когда локальный сайт работает, Cloudflare создаёт URL, но адрес не открывается в браузере или Telegram Mini App, а резервный туннель не появляется.

## Что изменено

- Добавлен третий независимый временный HTTPS-провайдер `localhost.run`.
- Cloudflare URL больше не назначается основным только потому, что строка URL появилась в логе.
- Все созданные адреса проверяются через `/health`; рабочий адрес поднимается на первое место.
- Если основной адрес перестал отвечать, рабочий резерв автоматически становится основным.
- Если оба публичных маршрута недоступны, launcher пересоздаёт туннели и перезапускает приложение с новыми URL.
- Telegram получает обновлённую Mini App ссылку после смены маршрута.
- Добавлен `FIX_MOBILE_ACCESS.cmd`: однокнопочная установка/настройка Tailscale Funnel и последующий запуск Boat Reserve.
- Исправлено ожидание повышенного PowerShell-процесса при установке Tailscale.
- Страница запуска больше не объявляет любой Cloudflare URL заведомо нерабочим; она показывает фактический результат браузерной проверки.

## Рекомендуемый запуск

Для постоянной мобильной ссылки один раз запустить `FIX_MOBILE_ACCESS.cmd`, подтвердить запрос Windows и войти в Tailscale. В дальнейшем достаточно `START_ALL.cmd`.

Без Tailscale обычный `START_ALL.cmd` пытается Cloudflare, localhost.run и Pinggy, проверяет их и выбирает отвечающий URL.
