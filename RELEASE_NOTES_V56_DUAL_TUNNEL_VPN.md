# Boat Reserve v5.6 — два независимых публичных входа

## Зачем это сделано

Один Quick Tunnel Cloudflare может конфликтовать с системным VPN, прокси, фильтрацией провайдера или блокировкой TCP/UDP 7844. Поэтому v5.6 больше не полагается на единственный канал.

## Новый запуск

`START_PUBLIC_SITE_AND_BOT.cmd` теперь:

1. Сначала запускает FastAPI локально и проверяет `/health`.
2. Создаёт HTTPS-туннель через `localhost.run` по SSH.
3. Параллельно создаёт резервный Cloudflare Tunnel по HTTP/2/IPv4.
4. Запускает Telegram-бота с основным и резервным адресом.
5. Показывает пользователю две кнопки, если оба адреса доступны.

Файлы адресов:

- `PUBLIC_URL_PRIMARY.txt`
- `PUBLIC_URL_BACKUP.txt`

## VPN и Telegram

Сайт и Telegram Bot API — разные сетевые соединения. При выключенном общем VPN Telegram-боту всё равно нужен доступ к `api.telegram.org`. Для этого можно указать отдельный HTTP/SOCKS5-прокси через `SET_TELEGRAM_PROXY.cmd`. Тогда весь Windows-трафик не требуется направлять через VPN.

## Диагностика

`DIAGNOSE_PUBLIC_SITE.cmd` отдельно проверяет:

- локальный FastAPI;
- основной и резервный HTTPS-адреса;
- порт 22 к localhost.run;
- порт 7844 к Cloudflare;
- порт 443 к Telegram;
- активные VPN-адаптеры и системный прокси;
- журналы всех процессов.
