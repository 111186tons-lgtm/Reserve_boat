BOAT RESERVE V6.0 — БЫСТРЫЙ ПУБЛИЧНЫЙ ЗАПУСК

1. Полностью распакуйте ZIP в отдельную папку.
2. Запустите STOP_BOAT_RESERVE.cmd.
3. Запустите START_PUBLIC_SITE_AND_BOT.cmd.
4. Не закрывайте главное окно.

В версии 6.0 Pinggy запускается через встроенный OpenSSH Windows на порту 443.
Большой файл Pinggy больше не скачивается, поэтому строки «Writing request stream...»
при обычном запуске быть не должно.

Если Pinggy недоступен, программа только тогда попытается скачать Cloudflare как резерв.
Актуальная ссылка появится в PUBLIC_URL.txt и на локальной странице запуска.
