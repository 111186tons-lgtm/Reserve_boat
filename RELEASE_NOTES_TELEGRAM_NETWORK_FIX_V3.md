# Telegram network fix V3

Исправления:

- подробная расшифровка `ConnectError` без утечки токена;
- отдельная диагностика DNS, TCP 443, TLS, прокси и Bot API;
- автоматическое использование системного прокси Windows;
- поддержка ручного HTTP/SOCKS5-прокси через `TELEGRAM_PROXY_URL`;
- использование системного хранилища сертификатов Windows;
- принудительный IPv4 для обхода проблем с IPv6-маршрутом;
- повтор соединения при временном сетевом сбое;
- чистая база без тестовых клиентов и броней.
