# Boat Reserve v5.8 — исправление запуска Windows

Исправлена ошибка PowerShell:

`The property 'Count' cannot be found on this object.`

Причина: Windows PowerShell разворачивает массив из одного сетевого подключения в одиночный объект. При включённом StrictMode у такого объекта отсутствовало свойство `Count`. Проверка занятого порта теперь всегда явно приводит результат к массиву и использует `Length`.

Дополнительно:

- все Telegram-служебные `.cmd` теперь сами создают `.venv` и устанавливают зависимости;
- больше не требуется предварительно запускать `START_BOT_ONLY.cmd`;
- сохранён автоматический выбор свободного порта `8000–8099`;
- сохранён Telegram-администратор `706944976`;
- токен и база перенесены без изменения.
