# Boat Reserve V5.9 — маршруты браузера и VPN

- Основной бесплатный публичный маршрут переведён на Pinggy CLI через обычный HTTPS/WebSocket-трафик на порту 443.
- Cloudflare Quick Tunnel сохранён как независимый резервный маршрут.
- Удалён обязательный localhost.run, который не запускался при закрытом SSH-порту 22.
- Локальная страница `/launch` теперь проверяет оба адреса из самого браузера, то есть через тот же VPN/прокси, которым реально пользуется пользователь.
- Для Pinggy-проверок добавлен заголовок, пропускающий одноразовую screening-страницу в автоматических тестах.
- Исправлен UTF-8 BOM во всех CMD-файлах; `cmd.exe` больше не видит `я╗┐@echo` как команду.
- Сохранены Telegram-бот, ID администратора 706944976, база и административные действия.

Бесплатные случайные адреса меняются после перезапуска. Для постоянного бесплатного адреса рекомендуется однократно настроить Tailscale Funnel либо использовать собственный домен с именованным Cloudflare Tunnel.
