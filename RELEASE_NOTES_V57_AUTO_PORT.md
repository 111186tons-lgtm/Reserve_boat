# Boat Reserve v5.7 — автоматическая очистка и выбор порта

- При запуске автоматически завершаются процессы, оставшиеся от предыдущего запуска этой копии Boat Reserve.
- Если порт 8000 занят старым Boat Reserve, старый процесс завершается.
- Если порт 8000 занят другой программой, автоматически выбирается свободный порт из диапазона 8000–8099.
- Выбранный порт передаётся FastAPI, Cloudflare Tunnel и localhost.run.
- Текущий порт сохраняется в `LOCAL_PORT.txt`.
- PID процессов сохраняются в `runtime_processes.json` для безопасной очистки после аварийного закрытия.
- Добавлен `STOP_BOAT_RESERVE.cmd` для принудительной остановки только процессов проекта.
- Диагностика теперь учитывает динамический порт.
