ПОДКЛЮЧЕНИЕ GOOGLE SHEETS + ОТДЕЛЬНЫХ КАЛЕНДАРЕЙ КАТЕРОВ

Каталог читается из Google Sheets уже сейчас. Авторизация нужна только для:
- записи подтверждённых броней в лист «Подтвержденные брони»;
- создания/обновления событий в Google Calendar;
- автоматического создания отдельного календаря для каждого катера.

1. Откройте Google Cloud Console.
2. Включите Google Sheets API и Google Calendar API.
3. Создайте OAuth Client ID типа Desktop app.
4. Скачанный JSON переименуйте в google-oauth-client.json и положите в корень Boat Reserve.
5. Запустите CONNECT_GOOGLE.cmd.
6. В браузере войдите в тот Google-аккаунт, где находится таблица «Бронь Катеров».
7. Разрешите доступ к таблицам и календарям.
8. Скрипт создаст/найдёт календари «Boat Reserve — Бангкок», «Boat Reserve — Фараон» и т. д. для всех 8 катеров и запишет ID в лист «Катера».
9. Перезапустите START_PUBLIC_SITE_AND_BOT.cmd.
10. В диспетчерской нажмите кнопку «Google Sheets».

После этого при подтверждении оплаты:
- бронь сохраняется локально;
- клиент получает сообщение в Telegram;
- строка добавляется/обновляется в «Подтвержденные брони»;
- событие добавляется/обновляется в календаре конкретного катера;
- повторная синхронизация не создаёт дубль.

Файлы google-oauth-client.json и google-oauth-token.json являются секретными. Не отправляйте их посторонним и не публикуйте.
