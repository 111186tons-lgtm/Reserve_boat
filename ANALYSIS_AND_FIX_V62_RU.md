# Анализ ошибки и исправление v6.2

## Что показал фактический журнал

Локальный FastAPI-сервер запускался корректно и отвечал `200 OK` на `/health`. Ошибка возникала после запуска Pinggy, когда PowerShell сразу читал ещё пустой лог-файл. `Get-Content -Raw` вернул `$null`, а `[regex]::Matches()` не принимает `null`, поэтому весь сценарий завершался и в блоке `finally` останавливал уже работающий сайт.

## Найденные слабые места предыдущего запуска

1. Гонка при чтении пустых логов Pinggy.
2. Большой PowerShell-файл отвечал сразу за окружение, процессы, порты, скачивание, туннели и разбор логов; одна необработанная ошибка останавливала всё.
3. Зависимости проверялись через `pip install` при каждом старте, поэтому окно заполнялось сотнями строк.
4. При неудаче публичного туннеля выключался и локальный сайт.
5. После обрыва обоих туннелей приложение завершалось вместо автоматического переподключения.
6. Загрузка Cloudflare могла показывать бесконечный счётчик записанных байтов.

## Что сделано

- Основной запуск перенесён в `scripts/public_launcher.py` на стандартной библиотеке Python.
- Пустой, отсутствующий или временно заблокированный лог безопасно возвращает пустую строку.
- Pinggy запускается официальной SSH-схемой через TCP 443 и встроенный Windows OpenSSH.
- Cloudflare остаётся резервом и скачивается тихо только один раз.
- Добавлена SHA-256 отметка `requirements.txt`: повторная установка зависимостей выполняется только после изменения файла.
- Если публичный маршрут не создан, локальный сайт и Telegram-бот остаются запущенными для диагностики.
- Если публичные маршруты оборвались позже, launcher пытается восстановить их автоматически и перезапускает приложение уже с новой ссылкой.
- `STOP_BOAT_RESERVE.cmd` и `DIAGNOSE_PUBLIC_SITE.cmd` переведены на отдельные небольшие Python-скрипты.
- CMD-файлы записаны в ASCII без BOM и с Windows CRLF.

## Проверка

- Компиляция трёх новых Python-скриптов пройдена.
- Добавлены тесты чтения пустых логов и извлечения ссылок Pinggy/Cloudflare.
- Полный набор проекта: 26 тестов пройдено.
