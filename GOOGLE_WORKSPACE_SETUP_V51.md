# Подключение Google Sheets и Google Calendar — V5.1

Платёжный сценарий работает без Google-интеграций: администратор подтверждает оплату, бронь создаётся в локальной базе, а клиент сразу видит подтверждение и рекомендации.

Чтобы дополнительно записывать подтверждённую бронь в лист **«Подтвержденные брони»** и создавать событие в Google Календаре, один раз подключите сервисный аккаунт.

## 1. Создайте сервисный аккаунт

1. Откройте Google Cloud Console и создайте или выберите проект.
2. Включите **Google Sheets API** и **Google Calendar API**.
3. Создайте сервисный аккаунт и JSON-ключ.
4. Сохраните ключ рядом с `run_windows.cmd` под именем:

```text
google-service-account.json
```

Файл ключа нельзя отправлять клиентам, добавлять в Git или класть в публичный архив.

## 2. Дайте сервисному аккаунту доступ

В JSON найдите поле `client_email`.

В таблице **«Бронь Катеров»** предоставьте этому адресу права редактора.

В Google Календаре создайте отдельный календарь, например **Boat Reserve**, и предоставьте сервисному аккаунту право изменять события. В настройках календаря скопируйте его ID.

После этого публичный доступ к таблице можно закрыть: V5.1 умеет читать её через авторизованный Google API.

## 3. Заполните `.env`

```env
GOOGLE_SERVICE_ACCOUNT_FILE=google-service-account.json
GOOGLE_CALENDAR_ID=ID_КАЛЕНДАРЯ
```

Вместо файла можно передать JSON через переменную `GOOGLE_SERVICE_ACCOUNT_JSON`, но локальный файл обычно проще.

## 4. Включите интеграции в Google-таблице

На листе **«Настройки»**:

- поставьте галочку `google_write_enabled`;
- поставьте галочку `google_calendar_enabled`;
- в `google_calendar_id` вставьте ID календаря.

`google_calendar_id` из таблицы имеет приоритет над `.env`.

## 5. Перезапустите приложение

После перезапуска нажмите **Google Sheets** в диспетчерской, чтобы загрузить настройки и шаблоны.

При следующем подтверждении оплаты приложение:

1. создаст бронь в базе;
2. сформирует сообщение из листа **«Шаблоны»**;
3. отправит Telegram-сообщение, если указан `TELEGRAM_BOT_TOKEN`;
4. добавит или обновит строку в **«Подтвержденные брони»**;
5. создаст или обновит событие в Google Календаре.

Операции идемпотентны: повторная синхронизация обновляет ту же строку и то же событие, не создавая дубликаты.

## 6. Проверка

Создайте тестовую заявку на будущую дату и пройдите сценарий:

1. клиент нажимает **«Я оплатил»**;
2. администратор открывает очередь оплат;
3. нажимает **«Подтвердить оплату»**;
4. клиент получает подтверждение;
5. в диспетчерской статус внешней синхронизации должен стать **«Синхронизировано»**;
6. строка должна появиться в таблице, событие — в календаре.

При ошибке в карточке заявки появится причина и кнопка повторной синхронизации.
