# Boat Reserve V7.2 — полная рабочая сборка

Сборка основана непосредственно на присланном рабочем архиве V7.1. Ничего из интерфейса, изображений, базы данных, бизнес-логики и накопленных исправлений V7.1 не заменено упрощённым проектом.

Изменения:
- добавлен `START_ALL.cmd`, вызывающий проверенный `START_PUBLIC_SITE_AND_BOT.cmd`;
- исключён PowerShell-launcher из предыдущей неработающей сборки;
- установлен новый Telegram-токен;
- `TELEGRAM_SETUP_PROFILE_ON_START=false`;
- `GOOGLE_SHEETS_SYNC_INTERVAL_SECONDS=0`;
- сохранена событийная синхронизация V7.1;
- версия приложения обновлена до 7.2.0.
